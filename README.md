# Foodie Restaurant Ordering Experience

Foodie is a responsive restaurant-ordering product concept built with React, Vite, and Tailwind CSS. The project demonstrates how a focused menu, shared application state, accessible controls, and clear feedback can create a coherent ordering flow.

## Features

- Responsive single-page restaurant experience
- Interactive featured-dish selector
- Reusable menu-card data model
- Cart with quantity controls, removal, and subtotal calculation
- Cart persistence with `localStorage`
- Multi-step demo checkout with confirmation state
- Persistent light and dark themes
- Keyboard-friendly controls and semantic HTML
- Reduced-motion support
- Scroll-triggered animation with AOS

## Technology

- React 18
- Vite
- Tailwind CSS
- React Icons
- React Slick
- AOS

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Project status

This is a portfolio prototype. The checkout flow does not transmit personal information, process payments, or place real restaurant orders.
